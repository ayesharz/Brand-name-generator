# Brand Name Generator

A simple and fun **Brand Name Generator** built using **HTML, CSS, and JavaScript**.
This project generates random brand names with a single button click.

## Features

* Random brand name generation
* Clean and simple UI
* Beginner-friendly JavaScript project
* Responsive design

## Technologies Used

* HTML
* CSS
* JavaScript

## How It Works

The project combines:

* A random **first word**
* A random **second word**
* A random **third word**

to generate unique brand names like:

* Tech Soft Solutions
* Info Sys Corp
* Data Ware Crazy
